# Mochi Studio — 개인용 웹사이트 & 이미지 게시판

피그마(Figma)의 모던한 에디토리얼/미니멀 디자인 트렌드를 반영하고, 귀여운 SVG 벡터 캐릭터와 **Supabase** 기반 로그인(아이디 저장) 및 이미지 게시판을 구현한 개인용 웹사이트입니다.

## 주요 기능

1. **Figma 스타일 모던 UI & 귀여운 벡터 캐릭터**
   - 따뜻한 오프화이트(`#FAF9F6`) 캔버스와 1px 헤어라인 보더, 부드러운 입체감
   - 인터랙티브 SVG 마스코트 **모찌(Mochi)** (눈 깜빡임, 둥실둥실 애니메이션, 클릭 시 말풍선 인사)
   - 로그인 모달의 **키키(Kiki)** 캐릭터 및 회원가입 시 선택 가능한 4종 귀여운 벡터 아바타

2. **Supabase 로그인 & 아이디 저장**
   - 이메일/비밀번호 기반 로그인 및 회원가입 (`supabase.auth`)
   - **아이디 저장** 체크박스 지원 (`localStorage`에 안전하게 저장 후 다음 방문 시 자동 입력)
   - Supabase 키가 없는 경우에도 즉시 체험할 수 있는 **로컬 데모 모드** 및 **1초 체험 로그인** 지원

3. **이미지 포함 게시판**
   - 드래그 앤 드롭 / 파일 선택 이미지 업로드 및 클라이언트 자동 리사이즈·압축
   - Supabase 연동 시 `post-images` Storage 버킷에 업로드 후 `posts` 테이블에 저장
   - 카테고리 필터(`전체`, `일상`, `작업노트`, `사진첩`), 실시간 검색, 좋아요, 이미지 라이트박스 확대 보기

## Supabase 실제 연동 방법

1. [Supabase](https://supabase.com)에서 새 프로젝트를 생성합니다.
2. **SQL Editor**에서 `supabase-schema.sql` 파일의 내용을 실행해 `posts` 테이블과 `post-images` 버킷을 생성합니다.
3. 웹사이트 우측 상단의 **`데모 모드`** 버튼을 클릭하고 **Project URL**과 **Anon Public Key**를 입력한 뒤 저장합니다.
